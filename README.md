# Arnaud Raulet

I help marketing and pricing teams answer "what actually caused this, and what should we do next?"
My toolkit is causal inference and Bayesian modeling: experiments, uplift, marketing mix models, price elasticity.
Data scientist based in Tokyo, working in French, English and Japanese.

## Projects

- **[marketing-causal-experimentation](https://github.com/a-raulet/marketing-causal-experimentation)**: which customers should get which email? Bayesian A/B/C test and uplift model on 64k customers; best email doubles conversion. PyMC, CausalML, FastAPI, Streamlit.
- **[dynamic-pricing-engine](https://github.com/a-raulet/dynamic-pricing-engine)**: which surge multiplier maximizes ride revenue? Bayesian elasticity, then bandits beating random pricing by 43% in simulation. PyMC, Thompson Sampling, Q-learning.
- **[mmm-robyn-project](https://github.com/a-raulet/mmm-robyn-project)**: how to reallocate a media budget? Marketing Mix Model with budget scenarios and a Shiny simulator. R, Robyn, Shiny.
- **[marketing-data-pipeline](https://github.com/a-raulet/marketing-data-pipeline)**: one daily view of spend, ROAS and CPA across 5 channels, from raw data to dashboard. BigQuery, dbt, Streamlit.
- **[realtime-clickstream-analytics](https://github.com/a-raulet/realtime-clickstream-analytics)**: e-commerce funnel and top products updated within seconds. Kafka, Spark Structured Streaming, Delta Lake.
